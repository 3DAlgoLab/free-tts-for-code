# Free TTS for Code - MVP Plan

Build a VS Code extension that reads selected code/text aloud using Piper TTS engine, with text filtering to sanitize input before synthesis.

## Goals

- Read aloud selected text (editor selection or terminal clipboard fallback)
- Voice selection from bundled voice models
- Text filtering: strip carriage returns, control characters, Unicode control chars before TTS
- Stop playback
- Bundle Piper binaries and default voices (same approach as Piper_TTS)

## Out of Scope (Phase 2+)

- Voice download from huggingface
- Voice removal
- API export for other extensions

## Checklist

- [ ] Extension scaffold: package.json, tsconfig.json, activation
- [ ] Text filtering module: sanitizeText() with tests
- [ ] Read aloud command: spawn Piper, pipe audio to platform player
- [ ] Stop playback command
- [ ] Voice selection command with quick pick
- [ ] Configuration: free-tts.voice setting
- [ ] Cross-platform binary resolution (getPiperPath, getPlaybackCommand)
- [ ] Context menu integration (editor/context)

## Verification

- Text filtering removes \r, control chars, zero-width spaces — unit tests pass
- Read aloud plays audio for selected text — manual test
- Stop playback kills running processes — manual test
- Voice selection switches active voice model — manual test
